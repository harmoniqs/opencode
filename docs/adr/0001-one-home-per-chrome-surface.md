# One home per chrome surface: the vault is a global drawer, the right column is the Work Column

Status: accepted (2026-08-01)

Tracking: harmoniqs/opencode#105 · Glossary: `CONTEXT.md` (Vault Drawer, Work Column, Status Popover)

Each of the titlebar's three right-side buttons drives exactly one surface backed by exactly one store, with no state-mirroring effects between them. The vault is the standalone left **Vault Drawer** on every route — its session side-panel tab is retired. The right column is the **Work Column**: files-changed navigator (default tab), context tree, and file tabs, owned solely by the per-session persisted `reviewPanel` store. Diffs open as full-column-width file tabs; the review panel never renders its own sidebar+content split inside the column. The **Status Popover** keeps its health + connections contents and is re-anchored honestly (the `shift={-168}` magic offset is deleted in favor of `bottom-end` placement with standard collision handling).

**Why:** the pre-merge build hosted the vault twice — the standalone drawer outside sessions and a side-panel tab inside — mirrored through two stores of different scope (module-scope `vaultPanel` signal vs per-session persisted `reviewPanel`), kept consistent by two `createEffect` mirrors plus a close-sync effect, and failing at it. Three user-visible bug classes resulted: (1) the vault button appeared dead on home/new-session — the drawer's fetch is keyed on `useServer().current`, which is unset when no server is focused, so the resource never fired and the host rendered an empty shell; (2) the vault and column toggles' pressed states could disagree with the screen, since two buttons wrote into one column through two stores; (3) the column squished the chat, because upstream's `ReviewPanelV2` renders its own file-list sidebar plus diff pane inside the column. Deleting the second host deletes the desync class rather than renting it; routing diffs to full-width file tabs deletes the squish; keying the drawer's fetch on a fallback server deletes the silent empty host.

**Conditions of merge (the hardening grafts):** `VaultBrowser` fetches against a fallback server (first healthy/connected) when none is focused; zero mounts render an attach-vault CTA that opens the Status Popover's connections tab; fetch failures render a named error with retry — nothing fails silently, which was bug (1)'s true sin. The column's tab strip is Changes (default) / Context / file tabs; a changed-file click opens its diff as a full-width file tab via the existing tab mechanism. Column default width drops to ~320px (resize handle retained); the sidebar-right button's pressed state binds directly to `reviewPanel.opened()` — the store has a single writer again. New i18n keys land in all 17 locales as English fallbacks (the merge's strict parity test demands it). Tests: `vaultPanel` store + tab-model unit tests updated (no vault tab); Storybook states for the column (loading / no-git / diffs / open diff tab); Playwright three-button flows across home, new-session, and session routes.

**Flip condition:** if upstream gains a center editor surface for file viewing, revisit routing diffs there instead of full-width column tabs. If the vault ever needs per-project scoping (different mounts per directory), revisit the global drawer in favor of a directory-scoped host.

**Accepted costs:** the in-session vault tab (2026-07-27) is removed weeks after landing — vault loses its tab-local adjacency to file tabs, and the drawer overlays the left strip in-session, spatially distant from the top-right button that summons it. `session-side-panel.tsx` remains a high-conflict file on upstream syncs, now carrying deliberate deletions the next merger must not resurrect (the `createEffect` mirrors and the vault tab trigger/content blocks).

**Considered:** minimal patch — repair the two sync effects, keep both hosts (runner-up: smallest diff, but preserves two writers into one column and rents the next desync); full chrome rethink — one panel system/store/host for every right-side surface (rejected: re-opens settled redesigns, blast radius spans just-merged upstream surface); session-tab-only vault with the titlebar button hidden elsewhere (rejected: vault unreachable from home/new-session, against the drawer's reason to exist).
